Recovery

Session-only controls for the active Slack client tab in this window. Each action reloads that tab. Other tabs are never targeted.

Bypass skips Slick startup. Safe mode loads Slick without plugins. Resume clears both flags; it does not change your saved settings.

Use these controls from the action popup while Slack is active. In a full options tab, recovery safely refuses to target a background tab. Requires scripting and host access to https://app.slack.com/*.

Experimental · limited compatibility

Slack updates can break renderer hooks; some workspaces and layouts may not work. This MVP has no desktop/native integrations, remote executable code, or credential permissions. No current tab URL or credentials are displayed here.
